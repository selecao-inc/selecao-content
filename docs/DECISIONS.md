# DECISIONS

## ADR-001 発信は別リポジトリ・サブドメインで行う（2026-11-16）

- 決定：公開先は `media.selecao.ai`、リポジトリは `selecao-inc/selecao-content`。
- 理由：記事の自動化で PR が多く流れるため、会社のサイト（selecao-ai）の PR・CI と切り離す。自動化の不具合が会社のサイトに及ばない。

## ADR-002 基盤は専用の infra/ と HCP Workspace で管理する（2026-11-16）

- 決定：このリポジトリに `infra/` を置き、HCP Terraform Workspace `selecao-content` で管理する。PAT・age 鍵は selecao-ai と分ける。リポジトリは public。
- 理由：別リポジトリにした目的と一貫し、権限と秘密情報の影響範囲を分けられる。PAT の期限は selecao-ai とそろえ（2027-10-21）、同じ日に更新する。

## ADR-003 記事とコードで確認の仕方を分ける（2026-11-16）

- 決定：記事の PR は事実確認（執筆と別のモデル）と人の確認。コードの PR は別のモデルのレビューと人の承認。両者を1つの PR に混ぜない。
- 決定：最初は記事の公開前に人の確認を入れる。外す時期は設計メモ §8 の基準を満たしたうえで人が判断する。
